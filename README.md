 # 刘思洋 · 个人主页

 深圳大学金融科技专业课程项目 —— 用规范化 AI 开发流程完成个人网站的发布与提交。

 ## 项目说明

 本项目为一个静态个人网站，展示内容包括个人简介、技能标签、模拟项目作品和联系方式。
 采用 Vibe → Spec → Build → Harness → Publish 的规范化流程开发。

 ## 目录结构

 ```
 ├── index.html              ← 主页面
 ├── assets/
 │   ├── style.css           ← 样式
 │   └── images/             ← 图片资源
 ├── docs/
 │   ├── prd.md              ← 产品需求文档
 │   ├── design.md           ← 设计说明
 │   └── checklist.md        ← 验收清单
 ├── report/
 │   └── final-report.md     ← 最终报告
 ├── screenshots/            ← 验收截图
 └── README.md               ← 本文件
 ```
