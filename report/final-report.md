 # 最终报告 · 个人网站

 ## 1. 项目定位

 本项目为深圳大学金融科技专业课程作业，使用规范化 AI 开发流程（Vibe → Spec → Build → Harness → Publish）完成个人网站的搭建与发布。
 目标用户为课程教师，网站内容为模拟用途，用于锻炼规范化开发流程的理解与实践。

 ## 2. 开发流程

 ### Vibe 阶段
 确定了个人定位：刘思洋，金融科技专业学生。明确了网站展示内容（个人简介、技能标签、模拟项目、联系方式）和隐私边界（Footer 标注模拟用途）。

 ### Spec 阶段
 产出三份规格文档：
 - `docs/prd.md` — 产品需求文档（范围、不做事项、成功标准）
 - `docs/design.md` — 设计说明（灰白简约风、配色、字体、文件映射）
 - `docs/checklist.md` — 验收清单（内容/功能/显示/工程/发布/提交六类）

 中途需求变更均先更新 Spec 文档，再实施编码。

 ### Build 阶段
 使用纯静态 HTML + CSS 搭建，不引入外部框架。核心功能：
 - 首页 OPEN LOGO → 引入页面（含彩蛋文字）
 - 五个主页面：关于、技能、项目、联系
 - Velvet Room 风格开门动画（瓷砖点击触发）
 - P5 风格黑白条纹边角装饰（配色修改版）
 - 三个项目详情页，每篇约 400 字技术描述
 - 图库系统：四大分区 → 二级子页面，可塑性记忆分区含 119 张图片
 - 图片查看器：滑动手势放大缩小（向外放大/向内缩小），旋转功能，操作提示
 - 彩蛋机制：contact → 首页 ×3 解锁图库集
 - GitHub Actions 自动健康检查

 ### Harness 阶段
 - 按 Checklist 逐项验收
 - 截图证据存放于 screenshots/ 目录
 - 23 次有意义的 Git 提交

 ## 3. AI 协作与个人判断

 **AI 参与的环节：**
 - 读取 PPT 说明文档并提取开发流程
 - 撰写 PRD、Design、Checklist 初稿
 - 生成 HTML/CSS 代码
 - 实现 Velvet Room 动画、彩蛋检测器
 - 生成项目详情页内容

 **个人做出的关键判断：**
 - 网站定位与内容边界
 - 配色方案（灰白简约 + 淡黄点缀）
 - 彩蛋解锁条件与游戏机制
 - 各分区图片素材的选择与命名
 - 是否使用 localStorage 方案或 GitHub Issues 方案

 ## 4. 验证结果

 - 桌面端（≥1024px）：无横向溢出，内容居中
 - 手机端（≤480px）：导航适配，文字可读
 - 所有内部链接可点击跳转
 - 图片查看器：滑动手势 + 旋转功能正常
 - 彩蛋机制：localStorage 跨页追踪正常
