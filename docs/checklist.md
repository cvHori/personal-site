 # Checklist · 个人网站验收清单

 > 每条完成标准必须对应一个能看见、能打开或能复现的证据。
 > 只有拿到证据后，才能把 `[ ]` 改成 `[x]`。

 ## 内容验收

 - [ ] Hero 区块展示一句话定位，无占位文字
 - [ ] About 区块包含完整的自我介绍（基于大学生模板）
 - [ ] Skills 区块展示至少 4 个技能标签
 - [ ] Projects 区块包含 2–3 个模拟项目卡片，标注「课程项目，数据为模拟样例」
 - [ ] Contact 区块包含邮箱和 GitHub 链接
 - [ ] Footer 显示「© 2026 刘思洋 · 课程项目示例，内容均为模拟用途」
 - [ ] 页面中无模板默认的占位姓名或虚构个人信息

 ## 功能验收

 - [ ] 导航栏各词条点击后平滑滚动到对应区块
 - [ ] 项目链接可点击，目标页面可正常打开
 - [ ] GitHub 链接可点击，跳转到正确地址
 - [ ] 联系方式中邮箱链接使用 `mailto:` 协议

 ## 显示验收

 - [ ] 桌面端（≥1024px）无横向溢出，内容居中
 - [ ] 手机端（≤480px）文字可读，无遮挡或重叠
 - [ ] 配色统一，不超过 2 个主色，无炫彩或不协调颜色
 - [ ] 图片正常显示，无裂图

 ## 工程验收

 - [ ] `docs/prd.md` 存在且与最终网站一致
 - [ ] `docs/design.md` 存在且与最终网站一致
 - [ ] `docs/checklist.md` 存在且已更新
 - [ ] `README.md` 存在，包含项目说明
 - [ ] `report/final-report.md` 存在
 - [ ] `screenshots/` 目录包含至少 4 张截图
 - [ ] Git 提交历史包含多次有意义的提交记录

 ## 发布验收

 - [ ] GitHub Pages 已配置，公开链接可访问
 - [ ] README.md 中记录了 GitHub Pages 正式链接
 - [ ] report/final-report.md 中记录了同一链接

 ## 提交验收

 - [ ] TA-Claw 提交包包含代码、三份文档、报告、截图
 - [ ] 已收到 Submitted successfully 回执
 - [ ] 提交包中不含 .env、密码、API Key、依赖目录或大文件
 ## 项目详情验收
 
 - [ ] 三个项目卡片均可点击跳转到独立详情页
 - [ ] 每个详情页包含约 400 字的项目描述，无占位文字
 - [ ] 每个详情页使用不同的背景图
 - [ ] 每个详情页有返回项目列表的链接，点击后正常跳转
 
 ## 彩蛋机制验收
 
 - [ ] introduction 页面显示彩蛋提示文字
 - [ ] 点击"联系"再返回首页，循环 3 次后解锁
 - [ ] 解锁后首页新增"图库"导航瓷砖，可点击跳转
 - [ ] 解锁后所有页面右下角显示"图库已解锁"标识
 - [ ] 未解锁时首页左下角显示当前进度（x/3）
 - [ ] localStorage 状态在页面关闭后不清除
 
 ## 图库集验收
 
 - [ ] gallery.html 存在且可正常访问
 - [ ] 图库集页面包含图片分类占位网格
 - [ ] 页面风格与主站一致（导航栏 + 边角 + 背景 + Footer）
