 # PRD · 个人网站产品需求文档

 ## 项目目标

 建立一个可长期更新的个人项目主页，通过完整实践「Vibe → Spec → Build → Harness → Publish → Submit」的规范化 AI 开发流程，积累网站开发与项目协作经验。

 ## 用户与场景

 - **主要用户**：课程教师（评估作业完成度与流程规范性）
 - **访问场景**：桌面浏览器与移动端浏览器直接访问 GitHub Pages 链接
 - **无实际访客群体**，页面内容全部为课程模拟用途

 ## 本期范围（本期做）

 五个基本页面区块：
 1. **Hero** — 一句话定位与视觉入口
 2. **About** — 简要自我介绍（基于大学生模板）
 3. **Skills** — 技能标签展示
 4. **Projects** — 2–3 个模拟课程项目卡片
 5. **Contact** — 公开联系方式（邮箱 / GitHub）

 ## 本期不做

 - ❌ 登录 / 注册系统
 - ❌ 数据库与后端服务
 - ❌ 支付相关功能
 - ❌ 复杂后台管理系统
 - ❌ 采集访客隐私数据
 - ❌ 繁杂版面与炫彩配色
 - ❌ 外部依赖框架（保持纯静态页面）

 ## 成功标准

 | 维度 | 标准 |
 |------|------|
 | 内容 | 五个区块齐全，无占位文字，信息为模拟样例并已标注 |
 | 功能 | 导航跳转、项目链接、联系方式可点击且目标有效 |
 | 显示 | 桌面端无横向溢出，移动端文字可读，无遮挡 |
 | 工程 | README、docs/ 三份文档、report/、screenshots/ 齐全 |
 | 发布 | GitHub Pages 可公开访问，链接写入 README |
 | 合规 | Footer 标注「课程项目示例，内容均为模拟用途」 |
 | 流程 | 小步多次 Commit，提交历史可追溯开发过程 |
 | 提交 | TA-Claw 提交包完整，包含代码、报告、截图与成功回执 |
 ### 新增：项目详情跳转
 
 - Projects 页面中每个项目卡片可点击，跳转到对应的独立详情页面
 - 每个详情页包含约 400 字的项目描述（技术架构、实现过程）
 - 每个详情页使用不同的背景图（来自 GIT 文件夹的未使用图片）
 - 详情页顶部有返回项目列表的链接
 
 ### 新增：彩蛋解锁与图库集
 
 - introduction 页面包含彩蛋提示文字，描述解锁条件
 - 彩蛋条件：用户点击"联系"页面再返回首页，累计 3 次循环后解锁图库集
 - 解锁后首页自动新增"图库"导航瓷砖
 - 所有已有页面底部右下角显示"图库已解锁"标识
 - 图库集页面展示图片分类占位（二次元、现实摄影、随手拍等）
 - 解锁进度在首页左下角显示（x/3）
 - 所有页面嵌入事件检测器（localStorage 跨页面追踪）
 
 ### 新增：本期不做（补充）
 
 - 不集成真实图片上传功能
 - 不替换图库集占位符为真实图片（后续由用户自行补充）
 - 不改变现有导航栏结构与边角装饰
